# KDE Store listing

## Product name

**cursorTrailOn — Animated Cursor Trail for KDE Plasma**

## Category

KWin Effects

## One-line description

A smooth, customizable trail for the mouse pointer and the text caret on KDE Plasma 6 and KWin Wayland.

## Long description

cursorTrailOn adds a continuous curved ribbon behind the mouse cursor and a fading smear behind the text caret. Unlike classic mouse trails that repeat cursor images, cursorTrailOn generates a smooth wind/slash shape whose width and lifetime react to movement speed.

It includes a native configuration panel with live preview, Crimson Slash, Wind White and Ice Blue presets, independent main/center/glow colors (or no glow), adjustable trail width, caret trail, intensity, trail duration, minimum activation speed, curve smoothing, and an option to disable the effect in full-screen apps and games.

cursorTrailOn is a native C++ KWin effect. The source package compiles and installs both the effect and its Plasma configuration module. Because native KWin plugins are linked against KWin, users may need to rebuild after KWin upgrades. Installation currently requires downloading the source archive and running the included installer; it is not a one-click KPackage effect.
